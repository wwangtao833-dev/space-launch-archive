# 人类飞行器发射行动档案

一个面向中文检索的人类飞行器发射行动数据库与静态网站。

## 当前目标
- 记录航天/飞行器发射行动的基本时间、国家/地区、发射组织、运载器、发射场、任务类型、目的地、载荷、结果等信息。
- 提供中文全文检索与多条件筛选。
- 数据与前端分离，便于后续持续批量扩充。
- 使用 GitHub Pages 部署静态站点。

## 目录
- `index.html`：网站主页面
- `styles.css`：页面样式
- `app.js`：检索、筛选、排序和统计逻辑
- `data/launches.json`：发射行动数据
- `data/schema.json`：数据字段定义
